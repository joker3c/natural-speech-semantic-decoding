# Natural Speech Semantic Decoding

This repository contains the source code for the manuscript "Decoding semantics from natural speech production using human intracranial EEG". We have included the decoding pipeline, figure-generation code, anonymized transcripts with precomputed word embeddings. Neural data archived at DABI (DOI: 10.18120/5jg5-j555).

## 1. Repository Layout

```text
.
├── Code/                            # Decoding pipeline for the paper Fig 1–3 experiments
├── Figure_Code/                     # Paper Fig 1–3 plotting code
├── Figure/                          # UPLOADED EMPTY: PDFs generated by fig1–3.py (§4.2)
├── Data_processed/                  # UPLOADED EMPTY: neural input data — fetch from DABI (§5.1)
├── Transcription/                   # Anonymized transcripts + row-aligned word embedding matrices
├── Parcellation/                    # Electrode–brain-area parcellation table + MNI coordinates
├── Matrix/                          # UPLOADED EMPTY: pipeline-generated cache (§3.4)
├── Decoding_Result/                 # UPLOADED EMPTY: decoding outputs (§3.5)
├── Statistics/                      # UPLOADED EMPTY: stats cache, regenerated by the plotting scripts (§3.6)
├── requirements.txt                 # Full environment freeze (minimal deps in Code/requirements.txt)
└── ReadMe.md
```

## 2. Code

### 2.1 `Code/` — Decoding Pipeline

Analysis code for the experiments behind paper Figures 1–3. Five top-level
scripts, one per experiment: `semantic_decoding.py` (main semantic decoding),
`phoneme_decoding.py` (phoneme control), `three_area_decoding.py` (three-area control),
`semantic_decoding_pos_tag.py` (content-word control), `semantic_decoding_semantic_dimension.py`
(semantic-dimension control).

- Configs: per-participant in `configs/<experiment>/<participant>.json` (`SemanticDecode/`,
  `Control_3Area/`, `Control_Phoneme/`, `Control_PosTag/`, `Control_SemanticDimension/`);
  group-level parameters in `configs_group/config.json`
- Modules: pipeline modules in `modules/` (`participant_data*.py`, `matrices*.py`,
  `transcription*.py`, `speech_decoder.py`)

Usage notes and the experiment ↔ script ↔ config mapping: `Code/README.md`.

### 2.2 `Figure_Code/` — Paper Figure Plotting Code

Three scripts — `fig1.py`, `fig2.py`, `fig3.py` — redraw paper Figures 1–3 from the analysis
results in this repository and write the PDFs to `Figure/figX/`. A vendored copy of
`decodingStatistics.py` is included under `Figure_Code/Code/modules/`. Panel ↔ PDF mapping is
documented in the header of each script.

## 3. Data

### 3.1 `Data_processed/`

`Envelope/Result/` holds the decoding-input neural features: **1,908 `.npy` files, one per
channel** (`{participant}_{electrode}_envelope.npy`) — the frequency-band envelope time
series. The folder ships empty on upload — fetch the data from the DABI archive (§5.1).

### 3.2 `Transcription/`

Anonymized transcripts + row-aligned embedding matrices:

```text
Transcription/
├── Conversation/PT01–14.csv          # one row per spoken word
└── Embedding/                        # all matrices row-aligned with the conversation CSVs
    ├── word2vec|fasttext|glove/PTxx.npy    # (n_rows, 300) float32, L2-normalized
    ├── word2vec_postag/PTxx.npy            # (n_rows, 300) float32 — content-word control
    └── SemanticDimension/
        ├── PTxx.npy                       # (n_rows, 6) float64 — SSDD semantic dimensions
        └── manifest_semantic_dimension.json
```

- `Conversation/PTxx.csv` columns: `start_time` / `end_time` (word onset/offset, s),
  `phoneme_group` (0–6, manner group of the word's first consonant), `pos_tag_keep`
  (1 = passes the content-word filter), `pos_tag_lemma_id` (opaque lemma ID, empty
  exactly where `pos_tag_keep = 0`).
- Words missing from a model are all-NaN rows, dropped at load time.

### 3.3 `Parcellation/`

- `parcellation.csv` — one row per implanted electrode (2,234 rows): `electrode`, `pid`,
  `area`, `hemi`, `broad_area`, etc.
- `pos.npy` — MNI x/y/z coordinates for the 1,910 analysis electrodes (rows with
  `janca_useful = 1` in `parcellation.csv`), row-aligned with that filtered subset;
  read by `Figure_Code/fig1.py`.

### 3.4 `Matrix/`

Per-seed decoding input matrices (`X/y …_seedN_pvalue….npy`) plus the per-participant
channel-selection CSVs (`*_electrode_freqband_binomial_test.csv`,
`*_electrode_freqband_seed_consistency.csv`, etc.).

- **Pipeline-generated cache**: the four matrix-generating scripts rebuild it from
  `Data_processed/` + `Transcription/` on every run (`GENERATE_MATRICES = True`); the one
  exception is `three_area_decoding.py`, which consumes the existing `Matrix_10Cluster/` as-is.
- Folders: `Matrix_10Cluster/` (word2vec main; also reused by the three-area control),
  `Matrix_{5,20,30}Cluster/`, `Matrix_Phoneme/`,
  `Matrix_10Cluster_{FastText,Glove,PosTag,SemanticDimension}/`.

### 3.5 `Decoding_Result/`

Decoding outputs written by the top-level scripts in `Code/`: one folder per experiment,
holding per-participant result tables (pickled pandas DataFrames, `.csv` suffix — one row
per seed × bootstrap draw of accuracy/F1/confusion/correlation metrics and predictions)
plus a `featureImportance/` subfolder.

### 3.6 `Statistics/`

Statistics summary caches read by the plotting code (regenerable by the analysis code): main
decoding results in `Statistic_Result/`, the control analyses in `Stats_3Area/`, `Stats_PosTag/`,
`Stats_SemanticDimension/`.

## 4. Running the Code

### 4.1 Decoding Pipeline

```bash
cd Code
pip install -r requirements.txt        # minimal deps; full freeze in repo-root requirements.txt
python semantic_decoding.py            # each script runs per participant via configs/<experiment>/<participant>.json
```

Run `semantic_decoding.py` before `three_area_decoding.py` — it consumes the existing
`Matrix_10Cluster/` cache (§3.4). The delivered pipeline reads pre-computed word vectors from
`Transcription/Embedding/`, so neither gensim nor the embedding models is needed (§5.2). Data
directories (`Data_processed/`, `Transcription/`, `Parcellation/`) resolve relative to `Code/`,
matching this repository layout.

### 4.2 Making Figures

```bash
cd Figure_Code
python fig2.py                         # Figure 2 (4 PDFs → Figure/fig2/)
python fig3.py                         # Figure 3 (4 PDFs → Figure/fig3/)
python fig1.py                         # Figure 1 (2 PDFs → Figure/fig1/; needs nilearn)
```

Set `MPLBACKEND=Agg` on headless machines. Fig 2A/2C/2D and Fig 3C read/rebuild the
`Statistics/` caches first.

### 4.3 Generated Folders — Uploaded Empty

Four result folders are code-generated and ship as **empty folders**; running the code above
populates them: `Matrix/` and `Decoding_Result/` are written by the decoding scripts (§4.1),
`Statistics/` and `Figure/` by the plotting scripts (§4.2). `Data_processed/` also ships empty,
but as **input** data rather than a generated result — fetch the neural features from the DABI
archive (§5.1).

## 5. External Data Sources

Two kinds of data are fetched from outside this repository:

### 5.1 Neural Data — DABI Archive

Raw and processed neural data are archived in the DABI database (accession **M6RES1N4MVA3**,
<https://doi.org/10.18120/5jg5-j555>).

### 5.2 Embedding Models — Needed Only to Re-run from Raw CSVs

`Embedding_model/` is not part of this delivery — the pipeline itself needs neither the models
nor gensim (§4.1). They are required only for re-runs from the raw CSVs: the raw branch of
`modules/transcription*.py` reads `../Embedding_model/...`. If needed, download the files below
into `Embedding_model/` as laid out in the table (`Glove/glove_readable.txt` is a
locally re-saved copy of `glove.42B.300d.txt`, faster to load). The files are too large to
redistribute:

| Folder | File | Source |
|---|---|---|
| `Embedding_model/Word2Vec/` | `GoogleNews-vectors-negative300.bin.gz` | Google Word2Vec — <https://code.google.com/archive/p/word2vec/> |
| `Embedding_model/FastText/` | `crawl-300d-2M-subword.bin` | fastText English word vectors — <https://fasttext.cc/docs/en/english-vectors.html> |
| `Embedding_model/Glove/` | `glove.42B.300d.txt` | GloVe pretrained vectors — <https://nlp.stanford.edu/projects/glove/> |
| `Embedding_model/SemanticDimension/` | `Estimated_semantic_dimensions_word2vec_English.csv` (SSDD16) | OSF — <https://doi.org/10.17605/OSF.IO/N5VKE> |
